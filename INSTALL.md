# Installation from GitHub

1. Make sure MeshCentral plugins are enabled.
2. Open the MeshCentral Plugin Manager.
3. Add the plugin configuration URL:

   ```text
   https://raw.githubusercontent.com/TeenKode/meshcentral-massenter/main/config.json
   ```

4. Install/enable **Mass Enter**.
5. Reload the MeshCentral web interface if necessary.
6. Open **My Devices**, select computers and click **Вход (Enter×2)**.
